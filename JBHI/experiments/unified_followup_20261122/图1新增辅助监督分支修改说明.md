# 图1新增辅助监督分支修改说明

**供作者手工制图。** 图中统一方法沿用 Causal-TabDiff 的条件扩散表征学习主干。以下位置和标记对应本轮实验 C 的计算路径。

1. **模块名称。** 建议标为“解剖约束的下一轮结节测量预测（训练期）”，英文标记为 “Anatomy-constrained next-screen measurements (training only)”。
2. **分支起点。** 在 C 与 D 区域衔接处明确标出“观测历史的共享纵向表征”。其输入是截至当前轮的真实记录，经独立吸烟条件调制的时间及特征注意力和有效轮次平均池化所得。历史去噪与这条观测历史路径共享主干参数。新增箭头从池化表征引出。图中若用单一箭头从逆扩散末端指向临床读出，建议将临床读出的上游明确为干净观测历史的编码。
3. **输入、输出和目标。** 分支输入是上述患者表征。输出含七分类（无记录正长径、五个具名肺叶、其他部位）、全肺最大长径、各非主导部位相对长径，以及记录为生长的结节相对长径。主导部位取全肺最大值，其余部位和生长标记尺寸均限制在全肺最大值内。训练标签取同一训练患者下一年度有合格 CT 记录的实测值。可以在图边放一只“下一轮真实 CT 测量（仅训练标签）”框，用箭头指向损失节点。
4. **箭头与梯度。** 实线向右画“共享表征 → 辅助头 → 解剖解码 → 测量损失”。真实目标也指向损失。用虚线反向标出“辅助损失 → 辅助头 → 共享主干参数”，避免将真实未来报告连入历史输入、风险头或吸烟条件。图例可用实线表示前向计算、虚线表示训练梯度。
5. **与两条既有结局分支的关系。** 从同一表征平行引出“两年诊断风险排序”“逐年首次诊断监督”和新增框。逐年和两年头均读取历史表征。常规评分读两年头。报告分支与两个结局头之间无需画分数传递箭头。
6. **训练与推断。** 训练层可标“有合格下一轮记录时启用测量损失”。所有主任务合格时点均可学习诊断，包括无下一轮 CT 或末轮 T2。推断层只保留“截至当前的历史＋基线吸烟条件 → 编码和池化 → 两年风险分数”。报告分支和去噪训练路径可用同一训练期图例标记。
7. **建议图注。** “Causal-TabDiff 由以基线吸烟状态为条件的双轴注意力主干编码截至当前轮的筛查历史。历史去噪、逐年诊断及两年诊断目标训练该表征。有真实后续 CT 测量的训练时点进一步提供解剖约束监督。常规预测直接由当前观测历史的共享表征给出两年诊断排序分数。”
