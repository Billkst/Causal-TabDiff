# 三项科学问题最终回答

每个差值均对应相同患者、相同预测时点上的明确对照。风险终点取随后两个研究年度内首次记录肺癌诊断，AUPRC 按三个开发折和三个种子等权平均。区间通过 2,000 次患者级配对自助抽样估计，条件于已拟合模型。多个种子共享同一组患者抽样权重。[原对照统计](../unified_followup_20261122/statistics/paired.json) · [修复对照统计](statistics/paired.json)

## 一　真实后续 CT 的普通辅助监督是否改善两年风险表征？

**B 对 A 未显示稳定增益。** A 的 AUPRC 为 0.03024，增加普通后续测量监督后 B 为 0.02905，配对差 −0.00119，95% 区间 [−0.00994, +0.00626]。9 个折与种子组合中只有 2 个差值为正。模型能从当前历史预测下一轮是否记录正长径，B 在合格 CT 上该任务的 AP 为 0.5863，该组报告中实际记录正长径的比例为 27.78%。能学到下一次检查的信息，与改善癌症诊断排序，是两个可分别检验的命题。

9,740 个时点具备合格的真实后续测量，其中 49 个时点属于两年诊断阳性。主风险任务保留全部 345 个阳性时点。这个覆盖差异说明训练期辅助分支实际获得了哪部分监督。一切 R 对 A 的差值都同时含有历史处理和辅助头的改变，不能用来替代 B 对 A 的单因素比较。[原队列及合格条件](../unified_followup_20261122/protocol.json)

## 二　相同测量标签采用解剖约束是否增加价值？

**确定性测量关系和部分测量预测得到了直接支持，风险排序有正向但跨折不均的信号。** 原 C 与 B 的训练人群、真实标签及监督机会相同。全肺最大径与六部位最大径不一致的比例从 B 的 12.94% 降至 C 的 0；强制走有正长径的预测分支时两者分别为 100% 和 0。下一轮记录正径的 Brier 从 0.19027 降至 0.16639，生长标记径 MAE 从 0.812 降至 0.448 mm。全肺径总体 MAE 从 2.051 增至 2.105 mm，说明对测量的影响取决于所评价的字段。

C 对 B 的诊断 AUPRC 配对差为 +0.00323 [ +0.00123, +0.00910 ]。三个开发折的均差依次为 −0.00011、+0.00068、+0.00911；原研究 13 项对照的同时单侧下界为 −0.00239。可以据此报告结构化监督的内部开发信号。P2 对 C0 的单因素检验只覆盖 dev0/42 的校准集，其独立临床排序效应没有三折估计。[原测量证据](../unified_followup_20261122/statistics/aux_means.csv) · [本轮单因素证据](locked.json)


修复后的完整组合 R 在 9,740 个可评价预测时点上保持全部所检验的解剖关系。相对 C，全肺径 MAE 由 2.105 降至 1.967 mm，患者配对差 −0.138 [−0.176, −0.100] mm。生长标记径 MAE 从 0.448 增至 0.493 mm，差 +0.045 [+0.017, +0.072] mm。额外正值的灵敏度仅 5.25%，应与零值特异度 97.34% 同时呈现。R−C 的诊断 AUPRC 为 −0.00012 [−0.00668, +0.00573]。这些是 P0 与 P2 的组合效应。[配对测量结果](statistics/paired_measurement.csv)

## 三　历史条件扩散对冻结方法是否提供独立贡献？

**它在下一轮全肺径、记录正径与生长标记径等报告终点上呈现价值，诊断排序的独立收益未获支持。** 原始历史目标下 C−D 的 AUPRC 为 −0.00391 [−0.01346, +0.00480]。前缀和稀疏修复后，R 的 AUPRC 为 0.03216，去掉历史学习的 N 为 0.03477。R−N 为 −0.00260 [−0.00777, +0.00101]，9 组中 3 组为正。微调均固定第十轮时，R−N 为 −0.00102 [−0.00507, +0.00290]。R 的 Top 5% 阳性时点覆盖为 15.79%，N 为 16.71%。这些结果也不足以宣布有扩散和无扩散两个方案等效。

在同一对 R、N 中，R 的全肺径 MAE 低 0.115 mm，95% 配对区间为降低 0.086–0.147 mm；生长标记径 MAE 低 0.060 mm，区间为降低 0.038–0.083 mm。这给出一个可以写入论文的发现：利用有效历史去噪及吸烟条件重建进行训练，影响了共享表征对后续报告的预测，但这类收益未转化为诊断排序优势。对照覆盖整套历史学习及其额外预训练预算；不区分单独去噪、条件重建或预训练各自的效应。[固定轮数对照](statistics/epoch10_paired.csv) · [完整模型比较](最终模型与实验对照汇总.md)

**锁定结论。** 统一方法能够从当时可获得的历史生成风险评分，并在训练时学习解剖一致的后续测量。其技术正确性和具体测量收益有直接证据。完整 R 相对 iTransformer 的诊断 AUPRC 差为 −0.00501 [−0.01736, +0.00285]。本轮结束算法研究，论文分别陈述测量学习与临床排序的证据。
