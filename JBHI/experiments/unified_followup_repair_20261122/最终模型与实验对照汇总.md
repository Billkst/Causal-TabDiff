# 最终模型与实验对照汇总

**最终冻结 R 的 AUPRC 为 0.03216，原完整模型 C 为 0.03228，修复后无历史扩散的 N 为 0.03477。** 这次修复改善了有效历史的处理和部分下一轮测量终点。两年肺癌排序未达到既定的基线增量目标。

## 对照的含义

| 版本 | 历史表征与训练 | 后续测量 | 本轮数据来源 |
|---|---|---|---|
| A | 原双轴模型与历史条件扩散 | 无辅助头 | 归档外折预测 |
| B | 同 A | 普通尺寸监督 | 归档外折预测 |
| C | 同 A | 稠密解剖头 | 归档外折预测 |
| D | 原双轴编码，去掉历史扩散目标与预训练 | 同 C | 归档外折预测 |
| R | P0 有效前缀双轴编码与掩码历史条件扩散 | P2 稀疏解剖头 | 本轮冻结后完整验证 |
| N | 与 R 相同的有效前缀编码，去掉历史扩散目标与预训练 | 同 R | 本轮冻结后完整验证 |

六者均使用 14 维当前及既往历史、独立吸烟条件、年度及两研究年度诊断监督。R、N 保留原阳性抽样与 Focal 权重。患者、结局、可用字段和风险评分输入协议一致；改变的是模型内部的掩码处理和训练目标。九基线全部复用原始预测，并逐单元重算指标。
