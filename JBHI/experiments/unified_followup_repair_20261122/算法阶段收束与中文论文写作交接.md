# 算法阶段收束与中文论文写作交接

**算法阶段按情况 B 结束。** 中文稿采用冻结版本 R 描述完整的 Causal-TabDiff，并以 N 检验历史扩散学习的独立作用。R 的全肺最大径预测改善，风险 AUPRC 为 0.03216，与原 C 的 0.03228 接近。相同前缀编码、相同稀疏辅助头、去掉历史扩散训练后，N 的 AUPRC 为 0.03477。对完整方法的解释应同时容纳这三个结果。下一阶段直接进入中文论证、章节重构与初稿完善。

## 全文唯一科学主线

**在肺癌诊断事件少、筛查历史短的条件下，真实后续 CT 测量及其解剖关系，能让当前历史表征学到什么，其中哪些信息能转化为两研究年度的高危识别？**

风险预测时只能看到当轮及此前的检查。训练时，有些患者还提供了下一轮可核实的测量报告。报告给出的监督比单个诊断标签更细：全肺最大径应与主导部位一致，余下部位可能全为零。研究将这组约束用于训练同一份历史表征，并分别检验它对报告预测和癌症排序的作用。最有辨识度的发现是两类终点发生了分化：正确编码后续测量提高了结构一致性并改善部分测量预测，临床排序的收益取决于对照，未呈现稳定的扩散优势。

沿用作者已确认的标题《Causal-TabDiff：面向肺癌纵向风险分层的条件扩散表征学习》。其中“面向风险分层”说明任务，“条件扩散表征学习”说明被研究的机制。两者之间的经验联系由实验回答。此前将未来报告实际生成后再对诊断年度积分的模型使用另一条推断路径；该模型的 0.05836 及其混合模型对照 0.06002 均不属于本稿统一方法的性能表。

## 最终方法版本与方法章节

| 方法段落 | 应交代的实质 | 证据位置 |
|---|---|---|
| 预测时点与临床信息 | 以 T0/T1/T2 为风险起点，仅输入可用前缀、正式 14 维历史及独立基线吸烟条件。后续两研究年度首次记录诊断是风险终点 | 原注册表与本轮 patient role 检查 |
| 共享纵向表征 | 时间轴屏蔽不可用轮次，特征轴按有效轮次归一化。吸烟条件调制双轴块。有效位置等权去噪，最后一次有效重建状态用于条件一致性监督 | repair.py 的 prefix_block、encode、history_terms |
| 风险分支 | 共享表征同时服务两年直接风险头及掩码年度诊断监督。部署时从当前表征直接给出排序分数 | engine.py 的训练与历史风险推断 |
| 训练期结构化后续测量 | 只有合格的真实下一轮 CT 参与监督。七类表示无正长径或六个主导部位，出现门处理非主导坐标与生长标记，正值比例受全肺径约束 | repair.py 的 sparse_report、auxiliary_loss |
| 训练与推断边界 | 共享主干同时接收风险、年度、辅助及历史任务梯度。常规推断不调用后续报告头，排序分数未经绝对风险校准 | 确定性梯度测试、权重回放、阈值定义 |

P1 的作用写入训练配置和实验解释。过采样和额外阳性损失权实质上放大了初始梯度，单因素校准没有支持移除其中一项。它属于经检验的原有训练选择。图 1 的未来测量箭头应从共享表示引出，并注明训练期回传；后续图件更新由作者本人完成，本轮研究记录不将旧图视作已完成该更新。

## Introduction 与 Experiments 的逐项对应

| 引言提出的问题 | 决定性对照 | 可直接用于正文的发现 |
|---|---|---|
| 普通真实后续测量能否强化当前风险排序？ | 原 B 对 A | AUPRC 差 −0.00119 [−0.00994, +0.00626]，普通辅助监督未显示稳定风险增益 |
| 同一组测量中，部位结构是否有用？ | 原 C 对 B；有正径分支上的一致性检查 | 全肺与部位最大径违例率从 12.94% 降至 0；C−B AUPRC +0.00323 [+0.00123, +0.00910]，5/9 个组合为正，原同时单侧下界 −0.00239 |
| 历史表征如何处理尚未发生的轮次和已核实的零值？ | P0 占位值扰动、梯度测试；P2 稀疏可表达性；固定折单因素校准 | P0 修复后占位值改变引起的风险 logit 差为零。P2 出现门有共享梯度。完整 R 的零值特异度 97.34%，相应正值灵敏度 5.25% |
| 正确处理这些结构后，完整模型改变了哪些终点？ | R 对 C，三折三种子 | 全肺径 MAE 降低 0.138 [0.100, 0.176] mm，生长标记径 MAE 增加 0.045 [0.017, 0.072] mm；诊断 AUPRC 差 −0.00012 [−0.00668, +0.00573] |
| 历史条件扩散的独立作用在哪里？ | R 对 N；原 C 对 D；固定微调轮数对照 | R 对 N 的全肺径 MAE 降低 0.115 [0.086, 0.147] mm；诊断 AUPRC 差 −0.00260 [−0.00777, +0.00101] |
| 对两年高危识别的实际水平如何？ | R 对九基线，同患者、输入与结局 | R 的 Top 5% 覆盖 15.79%，富集 3.16 倍；iTransformer 分别为 18.51%、3.70 倍。AUPRC 差 −0.00501 [−0.01736, +0.00285] |

正文中，把队列与终点放在所有比较之前。说明 10,594 名开发患者、31,587 个预测时点、345 个诊断阳性时点及 9,740 份合格后续监督，其中 49 个时点发生两年诊断阳性。报告预测以合格 CT 为分母；癌症排序以全部可评估时点为分母；不确定性估计以患者为抽样单位。随后先给同协议风险结果，再以机制对照解释读者看到的排序，再以测量误差与稀疏性分析说明辅助任务究竟学到了什么。

## 论文结论的边界与现成材料

- 研究支持历史前缀与稀疏解剖解码的计算正确性。下一轮全肺径及有无正径的预测有配对改善，生长标记误差的方向依对照而变。结构保证、尺寸误差和风险排序应分别报告。
- 诊断终点没有支持扩散的独立优势、完整 R 对原 C 的可靠提升，或超过最强原定基线 +0.003 的目标。现有区间也不足以断言方法等效。R 是预先冻结的完整方法，N 是同架构的无历史学习对照，不因外折排名更换模型身份。
- 稀疏门仍较少检出额外正部位。训练期可获得合格后续 CT 的诊断阳性时点有限，其对学习信号的影响可在 Discussion 讨论。三折开发证据不能外推为独立外部验证、临床净获益或吸烟的因果效应。这些问题均不阻止按现有证据写作。
- 正文取数使用完整验证汇总和配对表。单折校准数据只解释冻结决策。18 个新权重回放全部逐值相符，117 组归档终点已重算。21,188 名预留患者未进入本轮研究，算法阶段到此关闭。
